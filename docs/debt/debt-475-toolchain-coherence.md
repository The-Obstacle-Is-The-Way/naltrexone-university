### F9 — An interrupted local E2E run orphans the app server

At 2026-08-25 03:13Z, interrupting the required-E2E gate left Playwright's `next-server` listening on this clone's resolver-selected app port. `spawnCommand()` starts every child with inherited stdio but no detached process-group ownership, parent-signal handlers, or descendant cleanup (`scripts/e2e-local-orchestrator.ts:132-153`). Playwright correctly sets `reuseExistingServer: false` (`playwright.config.ts:45-49`), so the following run refused to start while the orphan held the port instead of silently testing an unknown server. The occupied port is therefore evidence of an orchestrator lifecycle defect, not a reason to weaken Playwright's isolation check.

### What the census did not find

- No mechanism on the earned list has a simpler primitive that covers its incident.
- Every `package.json` script is referenced somewhere, but four — `db:seed:prod`, `quality:crap`, `local:test:target`, `export:feedback` — have no workflow, hook, or script caller, only documentation.
- The seed format migration is complete: zero imported MDX files contain the old "Why other answers are wrong" form; the parser's rejection is now a regression fence and cheap to keep.
- The tj-actions-class exposure (job-scoped secrets, mutable tags) is DEBT-474, not this debt.

## Impact

1. **Trust tax on every run:** 8.65 s of scanner per `pnpm test` and per push, for a scan with a live blind spot (F5).
2. **Dead and redundant code kept alive by guards** (F2, F3): an 882-LOC orphan whose only dependents are its own tests and a scanner allowlist line, and a 575-LOC layer that duplicates a Compose flag.
3. **A fence repaired at the supported entries** (F4): #842 removed ambient-`CI` target authority, and Phase C mechanisms 7–8 put `export:feedback` and `db:generate` behind the existing human-command guard; the seed-time Vercel CLI choice remains an owner ruling.
4. **Lint rules written by hand** (F1): syntactic specifier, filename, and raw-JSX-element portions may be replaceable after red equivalence proofs; resolved-target, type-only, hook-placement, page-model, opacity, and typed-span contracts are semantic. The observational production line-count warning is deleted, not converted into a gate.
5. **Guards that red the lane for the wrong reason** (F6): a duplicated version literal, and an expiry with no advance warning.
6. **Interrupted-run contamination** (F9): an aborted local E2E run can leave this clone's app port occupied, blocking the next honest run and forcing a manual ownership check.
