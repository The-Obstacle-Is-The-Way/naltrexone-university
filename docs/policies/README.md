# Policies

Commitments the owner adopted. Their text changes only on the owner's instruction, and each keeps its adoption and effective dates.

- [Privacy Policy](./legal/privacy-policy.md) and [Terms of Service](./legal/terms-of-service.md), published at `/privacy` and `/terms`. The two consent-ruling data files beside them, in `legal/consent-rulings/`, are the checkout consent texts a test checks against.
- [Information security program](./security/information-security-program.md), [incident response and breach notification](./security/incident-response-and-breach-notification.md), and the [support cancellation procedure](./security/support-cancellation-procedure.md).
- [Supply chain](./supply-chain.md): dependency, advisory and licence policy.
