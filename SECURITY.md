# Security Policy

## Reporting a Vulnerability

Please report a security problem privately, never in a public issue, pull request or discussion:

- through GitHub's private vulnerability reporting, at https://github.com/The-Obstacle-Is-The-Way/naltrexone-university/security/advisories/new;
- or by email to support@addictionboards.com, with "Security" in the subject line.

Say what you found, how to reproduce it and what it affects. Do not access, change or delete anyone else's data, and do not degrade the service while testing.

## Scope

The service at https://addictionboards.com and the code in this repository. The same contact is published at https://addictionboards.com/.well-known/security.txt.
